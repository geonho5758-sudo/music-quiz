# 가사 한 소절 — 노래 가사 퀴즈

그림퀴즈랑 완전히 같은 방식으로 만든 팀전 노래 맞히기 게임이에요
같은 GitHub 저장소(japanese-quiz)에 파일만 추가하면 돼요

## 파일 구성

```
song.html    게임 본체 (건드릴 일 거의 없음)
songs.js     노래 데이터 ← 여기만 편집하면 됩니다
audio/       노래 클립(mp3) 넣는 곳
covers/      앨범 커버 이미지 넣는 곳
```

## 저장소에 추가하는 법

이미지 퀴즈 만들 때랑 똑같아요

1. 저장소 메인 화면에서 Add file → Upload files
2. `song.html`, `songs.js` 를 드래그해서 올리고 Commit
3. Add file → Create new file → 파일명에 `audio/keep.txt` 입력해서 폴더 만들기
   (covers 폴더도 똑같이 `covers/keep.txt` 로 만들기)
4. 각 폴더 안에 들어가서 mp3, 이미지 파일 업로드
5. 주소는 `.../song.html` 만 뒤에 붙이면 돼요
   (예: `https://아이디.github.io/japanese-quiz/song.html`)

## 노래 추가하기

`songs.js` 를 열어서 아래 형식으로 추가하면 끝입니다

```js
{
  id: "s2",
  level: "중급",
  lyric: "풀어쓴 가사 텍스트\n줄바꿈은 이렇게",
  hints: ["힌트1", "힌트2", "힌트3"],
  title: "노래 제목",
  artist: "아티스트명",
  cover: "covers/s2.jpg",
  audio: "audio/s2.mp3"
},
```

- `cover`, `audio` 가 아직 없으면 `null` 로 두면 돼요 (자리는 비워둔 채로 진행 가능)
- 오디오 클립은 **10~20초 정도로 짧게 잘라서** 넣는 걸 추천해요
  - 통째로 넣으면 업로드도 느리고, 정답 맞히자마자 바로 재생돼야
    텐션이 사니까요
  - 자르는 방법: 폰 기본 음성메모 앱, 또는 온라인 mp3 커터
    (`mp3cut.net` 같은 곳)로 원하는 구간만 잘라서 내보내면 돼요

## 조작법

그림퀴즈랑 완전히 동일해요

| 키 | 동작 |
|---|---|
| `P` | 문제표 열기 / 닫기 |
| `Space` | 힌트 1 → 2 → 3 → 정답 |
| `Enter` | 힌트 건너뛰고 바로 정답 |
| `←` / `→` | 이전 / 다음 문제 |
| `1` / `2` | 각 팀 +1점 |
| `Shift`+`1` / `2` | 각 팀 −1점 |

정답이 공개되는 순간 오디오가 자동 재생돼요, 다시 듣고 싶으면
화면에 뜨는 재생 컨트롤로 되감으면 됩니다

## 참고

- 문제표(`P`)에는 이제 정답이 안 보이고 "문제 1", "문제 2"로만 떠요,
  빔프로젝터에 띄운 채로 열어도 안전해요
- 무료 GitHub Pages는 저장소가 Public이어야 해서, 음원 파일도 이론상
  링크를 아는 사람은 들을 수 있는 상태예요 — 검색엔진에 노출되진
  않지만 완전 비공개는 아니라는 점만 참고해주세요
